METHODOLOGICAL INFORMATION
---------------------------

1. Description of methods used for collection/generation of data: For the collection of sequence enrichment data, we used next-generation sequencing performed at McMaster University in Hamilton, Ontario (https://genomics.healthsci.mcmaster.ca/wp-content/uploads/2022/06/amplicon_libraries_171031.pdf). For monitoring of fluorescence polarization (https://doi.org/10.1016/j.aca.2020.05.061), we used a Tecan Spark microplate reader (https://www.tecan.com/spark-overview). The settings used on the microplane reader that differ from the default include: a double orbital shake for 3 s at 72 rpm, G-factor of 1.000, 200 flashes, Gain of 89, dichroic 510 filter, Z-position of 18,800 mm, and a settle time of 100 ms.

2. Methods for processing the data: Data was analyzed and processed using GraphPad Prism version 10.2.2 (www.graphpad.com)

3. Instrument- or software-specific information needed to interpret the data: Software to analyze the next generation sequencing analysis include: Trimmomatic version 0.39 to trim the primer regions of the sequences obtained from next generation sequencing. The trimmed fastq.gz file was then converted to a .fastq file using the gunzip command in Terminal. This file was then analyzed by FASTAptamer 2.0 software (https://fastaptamer2.missouri.edu) to obtain grouped sequences. The potential aptamer sequences were further grouped into families based on sequence alignment (https://www.ebi.ac.uk/jdispatcher/msa/tcoffee?stype=protein) of the top 30 most abundant sequences.
