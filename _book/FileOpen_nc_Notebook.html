9.1 Overview

This tool provides an automated workflow for extracting and summarizing metadata from a collection of NetCDF (.nc) file, a self-describing format common in scientific fields. The workflow performs three main tasks:

  1. File discovery: It scans a specified directory for all NetCDF files.
  2. Metadata extraction: It uses the tidync package to pull out three fundamental components from each file:
    • Dimensions: The axes of the data grid (e.g., latitude, longitude, time).
    • Variables: The actual data stored in the file (e.g., temperature, pressure).
    • Attributes: Descriptive metadata, which can be global (applying to the whole file) or attached to specific variables (e.g., units).
  3. Report generation: It reshapes this metadata into user-friendly summary tables and saves them as .csv files.

9.5 Extract and organize metadata

Here, we will process each NetCDF file using purrr::map functions to extract its dimensions, variables, and attributes.

Code 
# Create a "safely" version of tidync to handle potentially corrupt files
safe_tidync <- purrr::safely(tidync)

# 1. Process all files, safely handling any errors
processed_files <- purrr::map(nc_files, ~safe_tidync(.x)) %>% 
  set_names(nc_files)

# 2. Separate successful results from errors
successful_results <- purrr::map(processed_files, "result") %>% 
  purrr::compact()

errors <- purrr::map(processed_files, "error") %>% 
  purrr::compact()

# Report any files that failed to process
if (length(errors) > 0) {
  message("The following files failed to process and were skipped:")
  walk(names(errors), message)
}

# 3. Extract and combine dimensions, variables, and attributes
nc_dimensions <- purrr::map(successful_results, ~.x$dimension) %>% 
  bind_rows(.id = "FileName")

nc_variables <- purrr::map(successful_results, ~.x$variable) %>% 
  bind_rows(.id = "FileName")

nc_attributes <- purrr::map(successful_results, ~.x$attribute) %>% 
  bind_rows(.id = "FileName")

print("Metadata extraction complete.")
[1] "Metadata extraction complete."
