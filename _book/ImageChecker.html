4.1 Overview

This notebook provides a workflow for performing standardized quality control checks on image files. It automatically scans a directory for common image formats (.jpg, .jpeg, .png, .tiff), extracts comprehensive metadata, and generates summary reports.

The process uses two specialized R packages to create two distinct levels of reporting:

  1. magick: Provides a high-level technical summary that allows the verification of valid images and checking elemental properties like dimensions, colorspace, and file size.

  2. exiftoolr: Performs a deep extraction of all embedded EXIF metadata, including camera/scanner model, software versions, GPS coordinates, and creation timestamps.

Finally, we offer a guide on how to use the extracted metadata to identify common curation issues, such as inconsistent image dimensions, missing location data, or potential privacy concerns.

4.5 Technical Summary with magick

The magick package allow us to confirm these files are readable and for extracting basic technical properties. This step loops through each file, reads its information, and collects it into a single table.

Code 
# Use purrr::map_dfr to efficiently loop through files and bind results
magick_info <- purrr::map_dfr(image_files, function(file_path) {
  tryCatch({
    # image_read() validates the file, image_info() extracts metadata
    image_read(file_path) %>%
      image_info() %>%
      # Add the filename to the summary table
      mutate(SourceFile = file_path)
  }, error = function(e) {
    # If a file is corrupt or not a valid image, print a warning
    message("Could not process file with magick: ", file_path, " | Error: ", e$message)
    # Return NULL for this file so map_dfr skips it
    return(NULL)
  })
})

# Display the first few rows of the technical summary table
print("--- Magick Technical Summary ---")

4.7.3 Check for Geospatial Information (Privacy/Completeness)

It’s important to know if your image files contain embedded GPS coordinates. This can be a privacy concern if the data is meant to be anonymous, or a completeness issue if the location data is required.

# Check for the presence of the GPSLatitude column
if ("GPSLatitude" %in% names(exif_info)) {
  
  gps_summary <- exif_info %>%
    summarise(
      files_with_gps = sum(!is.na(GPSLatitude)),
      files_missing_gps = sum(is.na(GPSLatitude)),
      total_files = n()
    )
  
  print("Summary of GPS Metadata:")
  print(gps_summary)
  
} else {
  
  print("No GPS metadata columns found in any of the files.")
  
}
