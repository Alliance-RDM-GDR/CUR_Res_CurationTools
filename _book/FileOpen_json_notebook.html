5.1 Overview

This notebook provides a workflow for inspecting and summarizing JSON (JavaScript Object Notation) files. JSON files are flexible and can store anything from simple flat tables to complex, deeply nested hierarchies.

The process performs four key checks for each file:

  1. Validation: Confirms the file is valid JSON and can be parsed.
  2. Structure Identification: Determines if the file represents a table (data frame), a list (hierarchy), or an array.
  3. Top-Level Key Extraction: Lists the main “branches” or column names to help understand the schema.
  4. Dimension Check: Reports the number of rows/columns (for tables) or the number of elements (for lists).

5.6 Generate a Report

This loop reads each file and attempts to summarize its contents. It handles errors gracefully (e.g., malformed syntax).

Code 
# 1. Initialize results list
json_summary_list <- list()

# 2. Loop through files
for (file_path in json_files) {
  file_name <- basename(file_path)
  
  tryCatch({
    # Attempt to parse the JSON
    # simplifyVector = TRUE allows R to detect tables automatically
    json_data <- fromJSON(file_path, simplifyVector = TRUE)
    
    # Determine Class (Data Frame, List, or Vector)
    obj_class <- class(json_data)[1]
    
    # Determine Dimensions & Keys based on type
    if (is.data.frame(json_data)) {
      dims_str <- paste(dim(json_data), collapse = " x ")
      keys_str <- paste(head(colnames(json_data), 5), collapse = ", ")
      if (ncol(json_data) > 5) keys_str <- paste(keys_str, "...")
      
    } else if (is.list(json_data)) {
      dims_str <- paste(length(json_data), "elements")
      keys_str <- paste(head(names(json_data), 5), collapse = ", ")
      if (length(json_data) > 5) keys_str <- paste(keys_str, "...")
      
    } else {
      # Atomic vectors or arrays
      dims_str <- paste(length(json_data), "length")
      keys_str <- "(No Keys - Flat Array)"
    }
    
    # Store success result
    json_summary_list[[length(json_summary_list) + 1]] <- tibble(
      FileName = file_name,
      IsValid = TRUE,
      StructureType = obj_class,
      Dimensions = dims_str,
      TopLevelKeys = keys_str
    )
    
  }, error = function(e) {
    # Store error result
    json_summary_list[[length(json_summary_list) + 1]] <- tibble(
      FileName = file_name,
      IsValid = FALSE,
      StructureType = "Error",
      Dimensions = "NA",
      TopLevelKeys = paste("Parse Error:", e$message)
    )
  })
}

# 3. Combine and Print
json_report <- bind_rows(json_summary_list)

print("--- JSON Structure Report ---")

5.7 Curation Insights

The StructureType column is your primary indicator of the data’s shape:

  • data.frame: Good news! This JSON is tabular (an array of objects) and acts like a CSV. The Dimensions column tells you how many records it holds.

  • list: This indicates a hierarchical or nested JSON. Use the TopLevelKeys to understand what categories of data it holds (e.g., metadata, data, citations).

  • IsValid = FALSE: These files are corrupted or contain invalid syntax (like trailing commas). They will break any downstream analysis pipeline and should be flagged immediately.
