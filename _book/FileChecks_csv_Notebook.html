3.1 Overview

This notebook provides a standardized procedure for checking and summarizing the contents of multiple .csv files within a directory. The goal is to automatically generate metadata summaries that can be used for data quality control, documentation, and initial exploratory analysis.

With this procedure curators can:

  • Discover files: Automatically find all .csv files in the project directory.
  • Extract metadata: For each file, gather information on column names, data types, and row counts.
  • Calculate descriptive statistics: Compute summary statistics (min, max, mean, median) and the count of missing values (NA) for each column.
  • Generate summary outputs: Create two final .csv files:
    1. MetaData_CSV.csv: A detailed, long-format summary of every column from every file.
    2. ColumnCheck_CSV.csv: A wide-format summary to easily compare column names and types across all files.

Assumptions:

  • This notebook is located and run in the root directory of the data deposit.
  • All compressed files (e.g., .zip, .tar) have already been extracted.

3.4 Generate metadata summaries

Here, the code will loop through each full file path in our csv.files list, read the file, and extract the required metadata.

3.4.1 Initializing the summary table

csv.summ <- data.frame(
  file.name = character(),
  column.name = character(),
  column.type = character(),
  rows = integer(),
  min = character(),
  mean = character(),
  med = character(),
  max = character(),
  NAs = character()
)

3.4.2 Processing each file

Here, we systematically loops through each CSV file selected to summarize the data and handle errors. For valid data, we extract metadata (like column names, data types, and row count), and calculate descriptive statistics (min, mean, max, and a count of missing values). When not valid columns are found (corrupted or contains unexpected data types) the script print a detailed message in the console identifying the problematic file and the specific error.

# The Main Loop: Processing Each File
for (i in csv.files) {
  
  # Use tryCatch to handle potential errors in a file without stopping the whole script
  tryCatch({
    
    # --- All the original processing code is placed inside the tryCatch block ---
    tmp <- read.csv(i)
    
    tmp.meta <- data.frame(
      file.name = basename(i),
      column.name = colnames(tmp),
      column.type = sapply(tmp, class),
      rows = nrow(tmp)
    )
    
    tmp.stat <- tmp %>%
      summarise(
        across(
          .cols = everything(),
          .fns = list(
            min = ~min(.x, na.rm = TRUE),
            mean = ~mean(.x, na.rm = TRUE),
            med = ~median(.x, na.rm = TRUE),
            max = ~max(.x, na.rm = TRUE),
            NAs = ~sum(is.na(.x))
          ),
          .names = "{.col}|{.fn}"
        )
      ) %>%
      mutate(
        across(everything(), as.character)
      ) %>%
      pivot_longer(
        cols = everything(),
        names_to = c("column.name", ".value"),
        names_pattern = "(.*)\\|(.*)"
      )
      
    tmp.meta <- full_join(tmp.meta, tmp.stat, by = "column.name")
    
    csv.summ <- bind_rows(csv.summ, tmp.meta)
    
  }, error = function(e) {
    # If an error occurs for a file, this code will run instead of crashing
    message(paste("--- ERROR --- Failed to process file:", i))
    message(paste("Specific error message:", e$message))
    message("Skipping this file and continuing with the next one.\n")
  })
}

# Clean up temporary variables from the loop
rm(tmp, tmp.stat, tmp.meta)

3.5 Create a comparison table

This step creates the wide-format col.compare table, making it easy to spot inconsistencies in column names and data types across files.

col.compare <- csv.summ %>%
  pivot_wider(
    id_cols = "file.name",
    names_from = "column.name",
    values_from = "column.type",
    values_fn = ~paste(., collapse = ", ")
  )
