# R Functions for Research Data Management — Quarto Book

This repository contains a Quarto book that documents R functions for day-to-day RDM tasks used by data curators.

## Quick start

- Install Quarto and R packages listed in the Preface.
- From this folder, build the book:

```bash
#Open bash chunks
quarto render
#Close bash chuck
```

## Structure

- `_quarto.yml` — book config
- `*.qmd` — chapters
- `R/` — helpers and functions
- `data/` — tiny input examples
- `styles/` — custom CSS
